# 🎵 Music Recommendation System

A Machine Learning-based music recommendation system that recommends songs similar to a selected song using audio features.

## 📌 Project Overview

This project uses Machine Learning to find songs that are musically similar to a selected song. The system analyzes audio features such as danceability, energy, loudness, acousticness, instrumentalness, valence, and tempo.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit

## 🤖 Machine Learning Approach

The project uses:

- StandardScaler for feature scaling
- Nearest Neighbors for finding similar songs
- Cosine similarity for measuring similarity between songs

## 📊 Audio Features

The recommendation system uses:

- Danceability
- Energy
- Loudness
- Speechiness
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo
